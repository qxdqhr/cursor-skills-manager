```bash

curl -s -H "Authorization: Bearer $TOKEN" \
  'http://127.0.0.1:3847/api/v1/skills' | jq '.data.total'
```

## 6. 已知问题与备注

1. **M2 代码尚未按子任务分批 `git commit`**：当前改动在工作区，提交前请执行 `pnpm typecheck && pnpm test && pnpm verify:m2`。
2. **部分 SKILL.md 的 YAML**（如 `project-bootstrap-remote-assets`）含未加引号的 `:`，解析会标 `PARSE_ERROR`，扫描仍收录该 skill。
3. **Web 端尚未对接 Bearer**：M3 需从 `config` 或设置页读取/保存 token。
4. **`indexUpsert` 单条增量更新**：M2 仅实现全量 `indexRebuild`，保存 skill 后的增量索引计划在编辑流程（M4）一并接入。
