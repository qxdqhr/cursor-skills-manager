## 4. 配置与数据文件（主库内）

路径：`~/.cursor/skills/`

| 路径 | 说明 | 进 Git |
|------|------|--------|
| `.csm/config.json` | 端口、locale、**api.token**、扫描路径 | ✅（Q1-C） |
| `.csm/index.sqlite` | FTS5 全文索引 | ✅（Q1-C） |
| `.csm/skills/*.json` | 逻辑标签（计划 v0.2） | 待定 |

首次启动 API 时若不存在 `config.json`，会自动创建并生成 Bearer token。

**调用需鉴权接口示例：**

```bash
TOKEN=$(jq -r '.api.token' ~/.cursor/skills/.csm/config.json)
curl -s -H "Authorization: Bearer $TOKEN" \
  'http://127.0.0.1:3847/api/v1/skills' | jq '.data.total'
```

## 6. 已知问题与备注

1. **部分 SKILL.md 的 YAML**（如 `project-bootstrap-remote-assets`）含未加引号的 `:`，解析会标 `PARSE_ERROR`，扫描仍收录该 skill。
2. **Web Token**：首次使用需在设置页粘贴 `~/.cursor/skills/.csm/config.json` 中的 `api.token`。
3. **`indexUpsert`**：M4 保存/新建后单条更新 FTS；删除时 `indexDelete`。
