## 1. 架构概览

```text
┌─────────────────┐   HTTP/JSON    ┌──────────────────────────────┐
│  apps/web       │ ◄──────────► │  apps/api (Bun/Node + Fastify) │
│  Vite + React   │  127.0.0.1    │  · REST                      │
│  i18n zh/en     │  Bearer Token │  · FS / Git / SQLite / Shell  │
└─────────────────┘               └──────────────┬───────────────┘
                                                   │
                    ┌──────────────────────────────┼──────────────────────────┐
                    │                              │                          │
            ~/.cursor/skills/              ~/.agents/skills/          ~/project/**/
            (Git 主库, 可写)               (symlink, 只读检查)         .cursor/skills/ (只读)
```

| 模块 | 职责 |
|------|------|
| `packages/core` | Skill 扫描、校验、索引、路径解析；无 HTTP 依赖，供 API 与后续 CLI 复用 |
| `apps/api` | REST、鉴权、调 core、执行 git/脚本 |
| `apps/web` | UI、i18n、调用 API |

## 2. 通用约定

### 2.1 Base URL

| 环境 | URL |
|------|-----|
| 开发 | `http://127.0.0.1:3847/api/v1` |
| 生产（本地） | 同上，端口读 `.csm/config.json` → `api.port` |

### 2.2 鉴权

| 项 | 说明 |
|----|------|
| 方式 | `Authorization: Bearer <token>` |
| Token 来源 | 首次启动 API 生成，写入 `.csm/config.json` → `api.token`（仅本机） |
| 绑定 | 仅 `127.0.0.1` / `::1` 监听 |
| 前端 | 启动后 `GET /api/v1/health` 返回 `hasToken`；无 token 时引导初始化 |

### 2.3 响应信封

**成功**

```json
{
  "ok": true,
  "data": { }
}
```

**失败**

```json
{
  "ok": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "name must match directory name",
    "details": { "field": "name", "expected": "mktest", "actual": "MkTest" }
  }
}
```

### 2.4 错误码

| code | HTTP | 说明 |
|------|------|------|
| `UNAUTHORIZED` | 401 | Token 无效或缺失 |
| `FORBIDDEN` | 403 | 项目只读 skill 尝试写入 |
| `NOT_FOUND` | 404 | skill / 文件不存在 |
| `VALIDATION_ERROR` | 400 | frontmatter / 路径校验失败 |
| `CONFLICT` | 409 | 目录已存在、Git 冲突 |
| `GIT_ERROR` | 502 | git 命令失败 |
| `SCRIPT_ERROR` | 502 | 归并/安装脚本失败 |
| `INDEX_ERROR` | 500 | SQLite 损坏，需重建 |
| `INTERNAL_ERROR` | 500 | 未分类错误 |

### 2.5 Skill 标识（全局唯一键）

API 使用 **`skillId`** 字符串，格式：

```text
personal:<relative-path-with-slashes>   # 相对主库根，不含 SKILL.md
project:<workspaceId>:<relative-path>
```

示例：

| skillId | 磁盘路径 |
|---------|----------|
| `personal:rn/rn-android-apk-flow` | `~/.cursor/skills/rn/rn-android-apk-flow/` |
| `personal:mktest` | `~/.cursor/skills/mktest/` |
| `project:profile-v1:build-utility-module` | `~/project/profile-v1/.cursor/skills/build-utility-module/` |

| 字段 | 类型 | 说明 |
|------|------|------|
| `source` | `"personal" \| "project"` | 数据来源 |
| `readOnly` | `boolean` | `project` 恒为 `true` |
| `name` | `string` | 叶子目录名 = Cursor 调用名 |
| `skillMdPath` | `string` | `SKILL.md` 绝对路径 |

## 3. 配置与元数据（文件层）

### 3.1 `.csm/config.json`

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `version` | `number` | 是 | `1` | 配置 schema 版本 |
| `locale` | `"zh" \| "en"` | 是 | `"zh"` | UI 语言（Q5-C） |
| `theme` | `"light" \| "dark" \| "system"` | 否 | `"system"` | 主题 |
| `api.port` | `number` | 否 | `3847` | API 端口 |
| `api.token` | `string` | 否 | — | Bearer token（自动生成） |
| `paths.personalRoot` | `string` | 是 | `~/.cursor/skills` | 主库绝对路径 |
| `paths.agentsRoot` | `string` | 否 | `~/.agents/skills` | 兼容目录 |
| `paths.projectScanGlobs` | `string[]` | 否 | `["~/project/**/.cursor/skills"]` | 项目 skill 扫描（Q2-B） |
| `paths.editor` | `string` | 否 | — | 打开目录命令，如 `cursor` / `code` |
| `reservedDirNames` | `string[]` | 否 | `["scripts",".git",".csm"]` | 扫描排除（仓库级） |

### 3.2 `.csm/skills/<skill-name>.json`（v0.2 逻辑元数据，MVP 可空）

| 字段 | 类型 | 说明 |
|------|------|------|
| `skillId` | `string` | 关联 personal skill |
| `categories` | `string[]` | 逻辑分类 |
| `tags` | `string[]` | 标签 |
| `favorite` | `boolean` | 收藏 |
| `note` | `string` | 备注 |

> **注意**：物理路径含子目录时，元数据文件键仍建议用 **叶子 `name`**；若重名冲突则改用完整 `skillId` 哈希文件名（实现阶段在 core 定一条规则即可）。

### 3.3 `SKILL.md` frontmatter（解析模型）

| 字段 | 类型 | 必填 | 校验 |
|------|------|------|------|
| `name` | `string` | 是 | `^[a-z0-9-]{1,64}$`，等于叶子目录名 |
| `description` | `string` | 是 | 非空，≤1024 字符 |
| `paths` | `string \| string[]` | 否 | glob，Cursor 规范 |
| `disable-model-invocation` | `boolean` | 否 | 默认 `true`（模板） |
| `metadata` | `Record<string, unknown>` | 否 | 任意键值 |

## 4. SQLite 索引（`.csm/index.sqlite`）

### 4.1 表结构

**`skills_fts`**（FTS5 虚拟表）

| 列 | 说明 |
|----|------|
| `skill_id` | 主键，与 API `skillId` 一致 |
| `name` | 叶子名 |
| `description` | frontmatter 摘要 |
| `body` | SKILL.md 正文（不含 frontmatter） |
| `source` | personal / project |
| `root_path` | 所属根目录绝对路径 |

**`skills_meta`**（普通表，辅助筛选）

| 列 | 类型 | 说明 |
|----|------|------|
| `skill_id` | TEXT PK | |
| `has_scripts` | INTEGER | 0/1 |
| `category_path` | TEXT | 物理分类，如 `rn` 或 `rn/android` |
| `mtime` | INTEGER | SKILL.md 修改时间 Unix ms |
| `validation_ok` | INTEGER | 0/1 |
| `git_dirty` | INTEGER | 0/1，仅 personal |

**`index_meta`**

| 列 | 说明 |
|----|------|
| `key` | 如 `schema_version`、`built_at` |
| `value` | TEXT |

### 4.2 索引生命周期（Q1-C）

| 操作 | 行为 |
|------|------|
| API 启动 | 校验 schema；失败或 `forceRebuild` 则全量重建 |
| 保存 SKILL.md | 增量更新对应 `skill_id` 行 |
| `POST /index/rebuild` | 全量重建并写回 sqlite 文件 |
| Git 检出后 | 可选 watcher 或手动触发 rebuild |

## 5. REST API

### 5.1 系统

无需鉴权（仅 localhost）。

**Response `data`**

```json
{
  "status": "ok",
  "version": "0.1.0",
  "personalRoot": "/home/qhr/.cursor/skills",
  "isGitRepo": true,
  "hasToken": true,
  "indexOk": true
}
```

#### `GET /config`

#### `PATCH /config`

**Body（部分更新）**

```json
{
  "locale": "en",
  "theme": "dark",
  "paths": {
    "projectScanGlobs": ["/home/qhr/project/**/.cursor/skills"]
  }
}
```

写入 `.csm/config.json`（personal 仓库内）。

### 5.2 Skill 列表与详情

#### `GET /skills`

查询参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `q` | string | 全文搜索关键词 |
| `source` | `personal,project` | 逗号分隔，默认全部 |
| `category` | string | 物理分类前缀 |
| `tag` | string | v0.2：逻辑标签 |
| `favorite` | boolean | v0.2 |
| `hasScripts` | boolean | |
| `gitDirty` | boolean | 仅 personal |
| `validationOk` | boolean | |
| `sort` | `name \| mtime \| path` | 默认 `name` |
| `order` | `asc \| desc` | |

**Response `data`**

```json
{
  "items": [
    {
      "skillId": "personal:mktest",
      "source": "personal",
      "readOnly": false,
      "name": "mktest",
      "description": "在 Next.js 项目中快速创建测试页面…",
      "categoryPath": "",
      "relativePath": "mktest",
      "rootPath": "/home/qhr/.cursor/skills",
      "skillMdPath": "/home/qhr/.cursor/skills/mktest/SKILL.md",
      "hasScripts": true,
      "mtime": 1716000000000,
      "validation": { "ok": true, "errors": [] },
      "git": { "dirty": false },
      "agentsLink": { "exists": true, "ok": true, "target": "/home/qhr/.cursor/skills/mktest" }
    }
  ],
  "total": 17
}
```

#### `GET /skills/:skillId`

URL 编码 `skillId`（`:` → `%3A`）。

**Response `data`**：在列表项基础上增加：

```json
{
  "frontmatter": {
    "name": "mktest",
    "description": "...",
    "disable-model-invocation": true
  },
  "bodyMarkdown": "# MkTest\n\n...",
  "files": [
    { "relativePath": "mktest.sh", "type": "script", "size": 1024 }
  ]
}
```

#### `GET /skills/tree`

返回分类树（物理路径聚合）。

```json
{
  "personal": [
    { "id": "rn", "label": "rn", "children": [], "skillCount": 4 }
  ],
  "project": [
    {
      "workspaceId": "profile-v1",
      "workspacePath": "/home/qhr/project/profile-v1",
      "categories": []
    }
  ]
}
```

### 5.3 Skill 写入（仅 `personal`，readOnly=false）

#### `POST /skills`

**Body**

```json
{
  "name": "my-new-skill",
  "categoryPath": "experiments",
  "template": "blank",
  "copyFromSkillId": null
}
```

**行为**：创建目录 + `SKILL.md` 模板；`name` 与目录名一致。

#### `PUT /skills/:skillId`

**Body**

```json
{
  "frontmatter": { "name": "mktest", "description": "..." },
  "bodyMarkdown": "# MkTest\n\n..."
}
```

**行为**：校验 → 原子写 `SKILL.md` → 更新索引。

**403**：`source=project` 或 `readOnly=true`。

#### `DELETE /skills/:skillId`

查询参数：`mode=soft|hard`（soft → 移至 `.csm/trash/<timestamp>-<name>/`）。

#### `POST /skills/:skillId/rename`

```json
{ "newName": "mk-test" }
```

同步更新 frontmatter `name` 与目录名。

#### `POST /skills/:skillId/move`

```json
{ "categoryPath": "rn" }
```

### 5.4 附属文件

#### `GET /skills/:skillId/files`

#### `GET /skills/:skillId/files/*relativePath`

读取 `scripts/`、`references/` 等文本文件。

#### `PUT /skills/:skillId/files/*relativePath`

仅 personal；禁止逃出 skill 目录（路径规范化 + 白名单扩展名 `.md|.sh|.py|.json|.ts` 等）。

### 5.5 校验

#### `POST /skills/validate`

不写入磁盘，用于编辑中实时校验。

**Body**

```json
{
  "skillId": "personal:mktest",
  "frontmatter": { "name": "mktest", "description": "x" },
  "bodyMarkdown": "..."
}
```

**Response**

```json
{
  "ok": false,
  "errors": [
    { "field": "name", "code": "NAME_DIR_MISMATCH", "message": "..." }
  ]
}
```

| 校验 code | 说明 |
|-----------|------|
| `NAME_REQUIRED` | 缺少 name |
| `NAME_INVALID` | 正则不符 |
| `NAME_DIR_MISMATCH` | name ≠ 目录名 |
| `DESCRIPTION_REQUIRED` | 缺少 description |
| `DESCRIPTION_TOO_LONG` | >1024 |
| `PATH_FORBIDDEN` | 试图写 skills-cursor 等 |

### 5.7 Git（仅主库仓库）

#### `GET /git/status`

```json
{
  "branch": "main",
  "clean": false,
  "files": [
    { "path": "mktest/SKILL.md", "status": "modified" }
  ]
}
```

#### `GET /git/diff`

查询：`path`（可选，相对仓库根）。

#### `POST /git/commit`

```json
{
  "message": "feat(skills): update mktest description",
  "paths": ["mktest/SKILL.md"]
}
```

`paths` 省略 = 暂存全部变更（仍限制在仓库内）。

#### `GET /git/log`

查询：`path`、`limit`（默认 20）。

## 6. 前端数据流（简要）

| 页面 | 主要 API |
|------|----------|
| 首页列表 | `GET /skills`, `GET /skills/tree` |
| 搜索 | `GET /search` 或 `GET /skills?q=` |
| 双栏编辑 | `GET /skills/:id`, `POST /skills/validate`, `PUT /skills/:id` |
| Git 侧栏 | `GET /git/status`, `GET /git/diff`, `POST /git/commit` |
| 设置 | `GET/PATCH /config` |
| 同步 agents | `POST /integrations/sync-agents` |

**只读项目 skill**：`readOnly===true` 时禁用 `PUT/DELETE/POST`；UI 显示徽章，v0.2 提供「复制到主库」→ `POST /skills` + 读项目文件内容。

## 7. `packages/core` 导出（内部 API）

| 函数 | 说明 |
|------|------|
| `scanPersonalSkills(root)` | 递归扫描主库 |

## 8. 安全与路径约束

| 规则 | 实现 |
|------|------|
| 路径穿越 | 所有写操作 `path.resolve` 后必须以 `skillRoot + '/'` 为前缀 |
| 禁止写入 | `~/.cursor/skills-cursor`、非 personal root、项目路径 |
| 命令执行 | 仅允许白名单脚本绝对路径；参数不拼接用户自由文本到 shell |
| CORS | 仅允许 `http://127.0.0.1:<webPort>` 与 `http://localhost:*` |
